# Supplied reference projects and brand assets

This Chest build was developed with the following user-provided archives as references:

- `minecraft-discord-bot-main.zip`
- `minecraft-discord-bot-master.zip`
- `CommandBlock-main.zip`

Original archives are bundled in `references/original-uploads/`. They are preserved for reference; Chest's current code should not be assumed to contain every feature from those projects. Check the relevant upstream license and notices before copying code or redistributing derivative work.

Generated branding boards are in `assets/branding/`. They contain visual concepts for logos, Discord avatars/banners, feature icons, command displays and dashboard layouts. Text in AI-generated mockups may be inaccurate; UI labels and commands should be taken from the actual application, not the image.
